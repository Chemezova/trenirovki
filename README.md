# Тренировки

Личный дневник тренировок: PWA без сервера, всё хранится на телефоне (IndexedDB).
Чистый HTML/CSS/JS без сборки — папку можно выкладывать на любой статический HTTPS-хостинг как есть.

## Локально

```
python -m http.server 8765 --directory app
```

Открыть http://localhost:8765. На localhost сервис-воркер не регистрируется, чтобы правки были видны сразу.
Тесты логики: http://localhost:8765/tests.html

## Выкладка на GitHub Pages

1. Репозиторий с содержимым этой папки в корне.
2. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)`.
3. Через минуту приложение доступно по адресу `https://<логин>.github.io/<репозиторий>/`.

После изменения файлов поднять `VERSION` в `sw.js` — тогда телефон точно заберёт новую версию
(при обычном запуске новые файлы подтягиваются в фоне и применяются со следующего открытия).

## Установка на iPhone

Safari → открыть адрес → «Поделиться» → «На экран „Домой“». Запускать с иконки, не из Safari.
