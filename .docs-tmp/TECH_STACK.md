# Стек приложения «Тренировки»

Обновлено: 10.11.2026 · версия приложения 19 (`app/version.js`, `app/sw.js`)

## Принцип

PWA без сервера и без сборки: чистые HTML, CSS и JS, папку `app` можно выкладывать на любой статический HTTPS-хостинг как есть. Данные хранятся только на телефоне.

**Внешних библиотек нет — и не добавлять их без согласования.** Никаких npm, фреймворков, CDN, бандлеров и TypeScript. Если задача кажется требующей библиотеки, сначала обсудить.

## Что используется

| Слой | Что | Где |
| --- | --- | --- |
| Язык | JavaScript ES2020+, нативные ES-модули (`<script type="module">`) | `app/js/*.js` |
| Разметка | HTML-строки в шаблонных литералах, рендер через `innerHTML` | `app/js/views.js`, `app/js/app.js` |
| Стили | Один CSS-файл, светлая и тёмная тема через `prefers-color-scheme` | `app/css/style.css` |
| Хранилище | IndexedDB, база `trenirovki`, версия схемы 2 | `app/js/db.js` |
| Офлайн | Service Worker, кэш `trenirovki-v<N>` | `app/sw.js` |
| Установка | Web App Manifest, иконки PNG | `app/manifest.webmanifest`, `app/icons/` |
| Звук и голос | Web Audio API, SpeechSynthesis (русский голос), вибрация | `app/js/sound.js` |
| Экран | Screen Wake Lock API — не гаснет во время тренировки | `app/js/sound.js` |
| Шаги | Apple Здоровье напрямую недоступно: «Команда» iPhone кладёт шаги в буфер, приложение парсит текст | `parseHealth` в `app/js/stats.js` |
| Копия данных | JSON-файл: окно «Поделиться» (Web Share API с файлами) или обычное скачивание | `doExport` в `app/js/app.js` |
| Фото | `<input type="file" accept="image/*">` без `capture` — iPhone предлагает и камеру, и галерею | `app/js/views.js` |
| Тесты | Самописные проверки в браузере, без фреймворка | `app/tests.html` |

Целевая платформа — Safari на iPhone, запуск с иконки на экране «Домой». Всё новое проверять на ограничения iOS: звук и речь включаются только из обработчика тапа, таймеры при заблокированном экране молчат.

## Инструменты вокруг приложения

| Что | Как |
| --- | --- |
| Локальный сервер | `python -m http.server 8765 --directory app` (конфигурация `trenirovki` в `.claude/launch.json`). На localhost сервис-воркер не регистрируется |

## Выкладка и откат

- Репозиторий GitHub `chemezova/trenirovki` содержит только содержимое `app` (документы в нём не хранятся). Папка `app/` на компьютере и репозиторий должны совпадать: после каждой выкладки из чата изменённые файлы переносятся в `app/`.
- Работа идёт в отдельной ветке; в `main` (то есть на сайт) — только после слова «выложи».
- `main` публикуется на GitHub Pages сразу.
- **Правило: перед каждым крупным обновлением сохраняется копия предыдущей версии** — отдельная ветка `backup-vN` (N — номер версии, которая сейчас на сайте). Только после этого новая версия попадает в `main`. Сейчас есть `backup-v15` и `backup-v17`; версия 16 восстанавливается по коммиту `4657ca5`.
- Откат: вернуть `main` к нужной ветке `backup-vN` (делает Claude по просьбе «откатить на N»). Данные на телефоне при откате не стираются, но поля новой версии старая не покажет — перед откатом лучше сохранить копию данных.
- История версий: 15 (25.10.2026) → 16 (03.11) → 17 (03.11) → 18 (10.11, выложена на сайт) → 19 (10.11).

## Правила при изменениях

- Новый файл в `app/` — добавить его в список `FILES` в `app/sw.js`, иначе офлайн он не загрузится.
- Любая выкладка: поднять `VERSION` в `app/sw.js` и `APP_VERSION` / `APP_DATE` в `app/version.js` (одним номером).
- Новое хранилище IndexedDB — поднять `VERSION` в `app/js/db.js` и добавить его в `STORES`, если оно должно попадать в копию данных.
- Новая логика — чистой функцией в `cycle`/`plan`/`stats`/`progression` с тестом в `tests.html`; после изменений все тесты должны быть зелёными.
- Всё, что относится к конкретному человеку, не зашивать в код — см. «Курс на универсальный продукт» в `ARCHITECTURE.md`.
