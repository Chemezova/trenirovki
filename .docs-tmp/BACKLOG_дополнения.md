# Что добавить в BACKLOG.md

Моего `BACKLOG.md` у меня нет, поэтому это отдельные пункты — вставь их в свой файл и присвой номера по порядку.

## Идеи

- **Фото в замерах** (спереди, сбоку, сзади): выбрать из галереи или снять, хранить на телефоне, смотреть по датам рядом. Сейчас в замерах только подсказка «снимай в Камере». Учесть: фото пока не входят в копию данных (#11). Приоритет: низкий.
- **Копия в облако без ручных шагов.** Сейчас копия сохраняется вручную через окно «Поделиться» и приложение «Файлы». Идеи: напоминание по расписанию, автоматическое имя папки, импорт последней копии одним нажатием. Приоритет: средний.
- **Длина шага — настройка.** Сейчас 1350 шагов на км для всех. Дать указать свой рост или длину шага. Приоритет: низкий (но нужно для универсальной версии).
- **Ходьба на графиках месяца.** Блок «Ходьба» в «Целях» показывает дни и недели; в «Итогах месяца» остаются только км по неделям. Привести к одному виду. Приоритет: низкий.
- **Отметка визита в клуб на прошедшем домашнем дне.** Сейчас задним числом можно отметить только групповое, бассейн и домашние занятия; сменить тип прошедшего дня на «клуб» нельзя. Приоритет: средний.
- **ИИ-помощник внутри приложения** (подсказки, разбор самочувствия). Требует сервера или встроенных возможностей Claude, отдельного решения про оплату и защиту данных. Приоритет: идея на будущее.

- **Пересчёт плиток в кг.** Сейчас при смене единицы подсказка начинает с нуля, потому что масса плитки на тренажёре неизвестна. Идея: в настройках упражнения указать «в одной плитке N кг» и пересчитывать историю автоматически. Нужен ответ Елены, сколько кг в плитке на её тренажёрах. Приоритет: низкий.
- **Домашний день по шагам.** Сейчас домашний день считается выполненным, если отмечена любая активность. Шаги, введённые вручную, создают запись ходьбы и закрывают день; шаги из Здоровья — нет. Решить: засчитывать домашний день, когда шагов не меньше плана. Приоритет: средний.

## Эпик: универсальное приложение для людей с ограничениями

Цель — чтобы приложением могли пользоваться другие люди, сохранив все настройки под Елену. Шаги (черновик, уточнить на следующих итерациях):

1. **Профиль пользователя.** Имя, цель (вес, объёмы, шаги), расписание тренировок, длина шага, клуб (окна зала и бассейна, групповые занятия) — вынести из кода (`plan.js`, `state.js`, `stats.js`) в данные. Елена остаётся первым профилем.
2. **Первый запуск (онбординг).** Несколько вопросов: цель, сколько раз в неделю, где тренируется (клуб/дом), ограничения.
3. **Модуль ограничений.** Отдельное понятие: зрение, шея, лишний вес, колени, спина и т. д. У каждого — запрещённые и осторожные упражнения, замены, стоп-сигналы, что показывать врачу. Сейчас всё это про глаза Елены и лежит в `data.js`.
4. **Библиотека программ.** Программы привязаны к ограничениям и уровню, а не к человеку. Цикл (13 недель, фазы) — шаблон, который можно менять.
5. **Данные и приватность.** Продумать, как хранить данные и делать копии, если пользователей много; юридические вопросы про здоровье (приложение не заменяет врача).
6. **Изоляция «личного».** Таблица «Что сейчас зашито под одного человека» в `ARCHITECTURE.md` — отправная точка.

Приоритет: высокий как направление; делать по одному шагу вместе с задачами по программе Елены.
